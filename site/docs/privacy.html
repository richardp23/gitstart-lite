Privacy

GitStart Lite is a local teaching tool. It runs on your machine with Bash and Git. It helps you learn Git workflows that often use a remote host. The tool itself does not phone home.

No telemetry

The application does not send usage data to GitStart or to a third party.

After the bootstrap download, the application does not contact the GitStart host.

No credential collection

GitStart does not ask for a password or a personal access token.

Git and your installed credential helper manage remote authentication.

Local data only

GitStart reads Git state in the directory you select. It does not upload file names or file contents to a server.

The diagnosis lesson builds a local text report. You choose whether to copy or share it.

Bootstrap download

The online bootstrap script downloads the release file over HTTPS. It uses a temporary directory and removes it on exit.
